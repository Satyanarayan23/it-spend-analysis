
# IT Spend Analysis

## What Are We Trying to Solve?

Organizations need to monitor IT spending, compare actual expenses against planned budgets and forecasts, and understand how technology costs are distributed across different regions, departments, and cost categories.

This Power BI project provides an interactive view of IT expenditure, helping stakeholders analyze budget performance, track spending trends, and identify areas where actual spending differs from planned budgets.

## What Each Page Shows

### 1. Read Me
Provides an introduction to the IT Spend Analysis report and its purpose.

### 2. Headline
Presents an overall summary of IT spending through key performance indicators, budget comparisons, forecast trends, and spending analysis across regions, IT areas, and cost element groups.

### 3. Regions
Explores IT spending across different geographical regions through comparative charts, detailed tables, a geographical map, and scatter chart analysis.

### 4. Decomposition
Provides a decomposition tree to explore and break down IT spending across different contributing dimensions.
